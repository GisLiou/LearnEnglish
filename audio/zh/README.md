# 浣浣中文台詞錄音清單

浣浣說中文的地方共有 13 句。錄好的檔案放在這個資料夾（`audio/zh`），檔名用下面的「代號」，例如 `welcome.mp3`。
錄好的代號要加進同資料夾 `index.js` 的清單裡，App 才會改播你的錄音；還沒錄的句子會繼續用手機內建語音。

> 最簡單的做法：用手機錄音 App 錄好（每句一個檔案，檔名取代號），全部傳給 Claude，
> 由 Claude 幫你轉成 mp3、剪掉前後空白、調整音量，並更新 `index.js`。

錄音小提醒：語氣活潑親切，像小浣熊跟朋友聊天；每句前後留約半秒安靜；在安靜的房間錄。
句子裡**不要唸出使用者的名字**（畫面上仍會顯示名字），這樣一份錄音所有人都能用。

| 代號 | 什麼時候出現 | 請錄這句話 |
|---|---|---|
| welcome | 第一次打開 App | 嗨，我是浣浣！歡迎來到浣浣學英文，你的名字是？ |
| rename-ask | 設定裡修改暱稱 | 想換成什麼名字呢？ |
| confirm-name | 輸入暱稱後確認 | 喔喔，這是你的名字嗎？ |
| saved-new | 第一次設定好暱稱 | 太好了！我會一直記得你的。我們一起開始學英文吧！ |
| saved-rename | 修改暱稱完成 | 好的！以後就這樣叫你囉。 |
| welcome-back | 之後每次打開 App | 歡迎回來！今天也一起學英文吧。 |
| placement-intro | 程度測驗開始前 | 我們先做個小測驗，看看從哪一課開始最適合你！不會的題目用猜的就好。 |
| placement-done | 程度測驗結束 | 測驗完成！我幫你找到最適合開始的單元了。前面的單元，隨時可以在自選課程複習。 |
| finish-perfect | 上完一課，全部第一次答對 | 太厲害了！這一課全部第一次就答對！ |
| finish-one | 上完一課，只錯 1 題 | 好棒！只錯了一題，下面有列出來，再聽一次就記住了。 |
| finish-good | 上完一課，答對 6 成以上 | 完成了！錯的題目已經重新練過，下面也有列出來。 |
| finish-low | 上完一課，答對不到 6 成 | 這一課可以再多練習一下。建議之後到自選課程再上一次，會更熟喔。 |
| finish-better | 接在上面那句後面：比上次進步時 | 而且比上次多答對了，真的進步了！ |
